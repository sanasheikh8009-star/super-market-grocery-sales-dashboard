AN AMEZING EXPERIENCE WITH EXCEL PROJECT
Super Market Grocery Sales Dashboard
About
This project is an Excel-based dashboard that analyzes retail sales performance. It provides key insights into sales data, helping to understand trends and performance.
Key Insights
 * Total Sales Analysis.
 * Performance by Product Categories.
 * Monthly Sales Trends.
Technologies Used
 * Microsoft Excel (Data Analysis and Visualization)
 * GitHub (Project Storage)
